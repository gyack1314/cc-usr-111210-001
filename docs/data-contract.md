# 发运交换资料口径

只处理UNOC语法3。默认服务字节为组件:、元素+、十进制.、释放?、保留空格、段终止单引号；UNA有9字节，不计业务段。换行不自动去除，原字节范围以零基半开区间计。

UNB第5个元素为控制引用，UNZ为消息数、控制引用；UNH为消息引用和DESADV:D:96A:UN，UNT为含首尾的段数及消息引用。CPS为当前包裹ID、可空父ID；PAC为包数与包装类型第3元素；LIN第1元素为行号，第3元素复合值为商品号:编码体系。PIA第2元素为补充商品复合标识，IMD第3元素的第4组件为自由描述，QTY第1元素为限定符:数量。只将QTY限定符12记发运数量，其他限定符保留原值。消息内当前CPS切换时清除当前LIN，CPS前业务行非法，PAC归CPS，PIA/IMD/QTY归LIN。

一个源文件包含一个交换，未知业务段只留原段。业务数量允许0和小数但不负，PAC包数非负整数。交换重采摘要取原字节，不合并不同控制引用。原文件含后置父和描述中转义的服务字符。
